# Frontend 설계 명세서

> 5.18 민주화운동 체험형 챗봇 — 프론트엔드 설계안  
> 프로젝트명: **오월의 증언** (1980, Gwangju)  
> 최초 작성: 2026-05-08

---

## 기술 스택

- **구현 방식**: 단일 HTML 파일 (`frontend/index.html`)
- **CSS**: Tailwind CSS CDN
- **폰트**: Google Fonts — Noto Sans KR
- **JS**: Vanilla JS (프레임워크 없음)
- **데이터 저장**: localStorage (엔딩 해금 기록)
- **백엔드 연동**: FastAPI (`http://localhost:8000`)

## 전체 화면 구조

```
① 시작화면
    ↓ "518로 들어가기" 클릭
② 기자 설정 화면
    ↓ "취재 시작" 클릭
③ 지도 화면 (취재 대상 선택)
    ↓ 마커 클릭 → 장소 설명 팝업 → "취재 시작하기"
④ 채팅 화면
    ↓ 엔딩 마커 감지 (<<실종>>, <<특종>>, <<탄압>>, <<발행>>)
⑤ 엔딩 화면
```

## ④ 채팅 화면

### 레이아웃
- 인스타그램 DM 스타일 말풍선
- 상단: 인물 프로필 (아바타 + 이름 + 날짜·장소)
- 우측 상단: 사이드패널 토글 버튼 (Claude 스타일 아이콘)
- 하단: 메시지 입력창 + 전송 버튼

### 인물별 색상 테마
| 인물 | 배경색 | 말풍선색 |
|------|--------|---------|
| 윤상원 | `#1a2340` | `#3B5BDB` |
| 박관현 | `#2a1a0d` | `#c0742a` |
| 문재학 | `#0d2218` | `#1a7a45` |
| 전두환 | `#2c1a1a` | `#8B0000` |
| 계엄사령관 | `#1a1a1a` | `#555555` |

### 타이핑 인디케이터
- AI 응답 대기 중 점 3개 바운스 애니메이션 표시
- CSS keyframe animation으로 구현

### 사이드패널 (취재 노트)
- 우측 상단 버튼 클릭 시 오른쪽에서 슬라이드인
- 취재 완료한 인물마다 핵심 발언 1~2줄 자동 기록
- 프로그레스바: 기사 작성 가능 여부 표시 (최소 3명 취재 시 활성화)
- "기사 작성하기" 버튼 (3명 이상 취재 시 활성화)

### 가해자 취재 제약 규칙
- 전두환·계엄사령관은 직접 대화 불가
- 비서·부관을 통해 간접 응답만 가능
- "보도하면 구금" 식의 압박·회유 응답만 허용
- 학살 명령·결정 행위를 플레이어가 선택하는 상황 절대 금지
- 가해자 행위 정당화·미화 응답 금지

## ⑤ 엔딩 화면

### 엔딩 분기
| 엔딩 | 조건 | 제목 |
|------|------|------|
| A. 증언 기사 | 피해자(윤상원·박관현·문재학) 중 1~2명만 취재 | "당신의 기사가 발행되었습니다" |
| B. 특종 기사 | 피해자 + 가해자 모두 취재 | "역사적 특종이 세계로 타전되었습니다" |
| C. 보도 탄압 | 가해자 취재 시도 후 강제 추방 | "당신은 추방되었습니다. 그러나 기사는 살아남았습니다" |
| 🔴 스페셜: 실종 기자 | 가해자만 집중 취재 시도 | "당신은 실종되었습니다. 필름만이 남았습니다" |

### 엔딩 화면 구성
- 엔딩 제목 + 짧은 결말 서사
- AI가 취재 내용 기반으로 실제 기사 형태로 자동 생성 (엔딩 A·B)
  - 기사 형식: 날짜·소속·제목·본문
- "다시 취재하기" 버튼
- 해금된 엔딩 목록 표시 (localStorage)

### 엔딩 감지 방식
- AI 응답에 마커 포함 시 감지:
  - `<<발행>>` → 엔딩 A
  - `<<특종>>` → 엔딩 B
  - `<<탄압>>` → 엔딩 C
  - `<<실종>>` → 스페셜 엔딩

## API 연동

### 사용 엔드포인트
```
POST   /sessions                     세션 생성 (기자 설정 완료 시)
POST   /sessions/{id}/chat           메시지 전송
GET    /sessions/{id}/messages       대화 기록 조회
DELETE /sessions/{id}                세션 종료
```

### 세션 생성 요청
```json
{
  "player_name": "홍길동",
  "player_age": 30,
  "player_job": "AP통신 기자"
}
```

### 채팅 요청
```json
{
  "message": "왜 도청을 떠나지 않으셨습니까?"
}
```

## 코딩 규칙

- 단일 파일 (`frontend/index.html`)에 HTML·CSS·JS 모두 포함
- Tailwind 유틸리티 클래스 우선 사용, 커스텀 CSS는 `<style>` 태그 최소화
- 한국어 주석 작성
- 하드코딩된 API URL 금지 → 상수로 분리 (`const API_BASE = 'http://localhost:8000'`)
- 모바일 반응형 고려 (모바일 우선)
